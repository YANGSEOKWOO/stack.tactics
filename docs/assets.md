# 에셋 — 기물 (Assets / Units)

> **원천(source of truth):** `src/data/units.js`(`DEFS`), `src/data/recipes.js`(`RECIPES`), `src/data/economy.js`(`STAR_MULT`, `ODDS`).
> 아래 HP/ATK/코스트는 **현재 코드에 구현된 값**이며 플레이테스트 시작점이다.
> "역할 / 고유 능력" 칸은 아직 코드에 없는 **설계 영역**이다 — 현재 전투는 기본 자동공격만 동작한다.

## 공통 규칙

- **코스트 = 희귀도.** 레벨이 오를수록 고코스트 등장 확률 ↑ (상점 확률표는 맨 아래).
- **별업 배율 `STAR_MULT = [×1, ×1.8, ×3.2]`** — HP·ATK에 동일 적용, 반올림.
  - 예) JS(35/9) → ★★ 63/16 → ★★★ 112/29
- **합성 유닛도 별업 가능** (같은 합성 3개 → ★★).
