# 시너지 — 트레잇 (Synergies / Traits)

> **원천(source of truth):** `src/data/traits.js`(`TRAIT_DEFS`), `src/engine/synergy.js`(`computeCounts`, `computeBuffs`), `src/data/units.js`(`DEFS[*].traits`).
> 시너지는 **보드 위 카테고리 카운트**가 임계값을 넘으면 **팀 전체**에 발동한다.

## 카운팅 규칙

- 일반 기물: 자기 카테고리에 **+1**
- 합성 유닛: `traits` 정의대로 기여 (보통 **+2**, 멀티카테고리 합성은 여러 트레잇에 동시 +2)
  - 예) `Web App` 1체 = frontend +2 **그리고** backend +2 → 합성 한 방으로 두 트레잇을 동시에 당김
- 별업(★)은 카운트에 영향 없음 (스탯만 강해짐)

## 트레잇 4종 (현재 구현)

| 트레잇 | 단계 1 | 단계 2 | 효과 | 소속 기물 |
|---|---|---|---|---|
| **Frontend** | 2 | 4 | 팀 공격력 **+20% / +45%** | HTML, CSS, JS, React |
| **Backend** | 2 | 4 | 팀 최대 체력 **+25% / +50%** | Node, Java, Python, Go |
| **Database** | 2 | 3 | 초당 체력 회복 **+5 / +12** | Redis, Mongo, Postgres |
| **Infra** | 2 | 3 | 받는 피해 **-15% / -30%** | VPC, SG, LB, Docker, K8s |

### 합성 유닛의 트레잇 기여
| 합성 유닛 | frontend | backend | database | infra |
|---|---|---|---|---|
| Frontend | +2 | | | |
| Backend | | +2 | | |
| DataLayer | | | +2 | |
| Infra | | | | +2 |
| Web App | +2 | +2 | | |
| Full Stack | +2 | +2 | +2 | |

> 즉 `Full Stack` 1체만 있어도 frontend·backend·database가 각각 2씩 차서 세 트레잇 단계 1이 동시에 켜진다.

## 적용 방식 (전투)

- **Frontend(ATK), Backend(HP)** → 전투 시작 시 플레이어 유닛 스탯에 곱연산 적용
- **Infra(피해 감소)** → 매 틱 적 공격 피해에 `×(1 - 감소율)`
- **Database(회복)** → 매 틱 살아있는 아군 회복

## 설계 의도

- **가로축(합성)을 강화하는 장치.** 합성하면 카테고리 카운트에 2 기여하므로, "합성 = 시너지 가속"이 된다. → 세로축(별업)과의 경쟁 구도 형성.
- 지금은 **팀 전체 버프**라 단순/직관적. (TFT식 "트레잇 소속 유닛만 버프"로 바꾸면 더 전략적이지만 복잡해짐 — 열린 질문.)
